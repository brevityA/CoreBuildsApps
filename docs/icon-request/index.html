Why is this on a separate page instead of opening GitHub directly?

The TV could point its code straight at GitHub — it used to. Two real-world hops kept dropping the payload before it landed: the GitHub app claims github.com links and opens a blank native form, and logged-out logins can lose fields. This page always renders the values in a normal browser, so what you submit is what you see.

If “Open the GitHub issue form” ever hands you to the GitHub app with empty fields, use the app's menu → Open in browser, or hold the button and copy the link instead. The phone photos: a picture of the TV panel showing the app's current icon is genuinely useful — attach it to the issue if you have one.
