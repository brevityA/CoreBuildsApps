Core Builds Icon Pack — Privacy Policy

The app collects nothing about you. This page is the complete account of what leaves your device, when, and where it goes.

Applies to: Core Builds Icon Pack, package tv.corebuilds.iconpack (GitHub / Downloader build) and tv.corebuilds.iconpack.play (Google Play build), including the companion Core Builds Glyphs Pack.

Effective: 20 October 2026.

There is no account, and no profile

The app has no sign-in, no user identifier and no analytics, advertising or crash-reporting library. It does not read your advertising ID, your contacts, your location, your files or your installed-app list beyond the launcher query described below. Nothing is collected in the background.

No third party receives anything else. There is no advertising network, no data broker, no analytics provider and no server of ours that stores your activity. The broker, when it is enabled, keeps only a rate-limit window so one device cannot file hundreds of requests.

What the app reads on your device

To tell you which of your apps the icon pack covers, the auditor asks Android which apps have a launcher entry. It reads app names and component names to show you that list. That list stays on your device; it is sent nowhere, in whole or in part, unless you press Request icon for one specific app, which sends only that app's name and component.

What the app writes

If you use Export, wallpaper masters are copied into Pictures/CoreBuilds on your own storage so a launcher such as Monet can rotate them. Downloaded wallpapers and loops are cached in the app's private storage. Both are yours, and both are removed when you clear the app's data or uninstall it.

Permissions, and why each exists

  • Internet — to download wallpapers, loops and (on the GitHub build) the update check.
  • Network state — to report "no connection" instead of failing silently when you tap a wallpaper.
  • Set wallpaper — to apply a wallpaper you choose.
  • Write external storage (Android 9 and older only) — for the Pictures export on those versions.
  • Install unknown apps — GitHub / Downloader build only, for its own self-update and the Glyphs companion. The Play build removes this permission entirely.

Purchases

The Google Play version currently offers no purchases. If an optional paid upgrade is added later, payment is processed by Google Play, and no card or billing detail ever reaches the app — the app would learn only whether your account owns the item.

Children

The app is a wallpaper and icon pack. It has no social features, no user content, no chat and no advertising, and it collects no personal information from anyone, including children.

Your control

Because nothing is collected, there is nothing to request, correct, export or delete. Clearing the app's data removes its settings and cache. If you have already filed an icon request as a GitHub issue, that issue lives in a public repository and can be edited or deleted by you from your GitHub account.

Changes to this policy

If a future version sends anything the table above does not list, this page grows a row for it before that version ships, and the effective date changes. The app's own About screen carries the same complete list, so the two can be compared rather than trusted.
