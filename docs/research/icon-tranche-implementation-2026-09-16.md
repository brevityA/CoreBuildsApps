# Icon tranche implementation checkpoint

**Date:** 2026-09-16 (Australia/Sydney)

This checkpoint records the first implementation group from the committed
2026-09-15/16 research. It is not release approval and does not bump the
production version.

## Implemented redraws

| App | Drawable | Core construction | Mapping changed? |
|---|---|---|---|
| AirScreen | `airscreen` | Peaked open AS monogram with a rounded, flat-ended S | No |
| Aerial Views | `aerialviews` | Low sun behind two asymmetric overlapping landscape layers | No |
| AnyDesk | `anydeskandroid` | Two opposed diamond-chevron forms with a preserved negative gap | No |
| DW | `dw` | Overlapping circular bodies; outlined D on the left and masked W cut-out on the solid right body | No |

All four are original geometry in `tools/glyphs.py`. No vendor artwork,
fixed background, or launcher component was imported. The catalog components
remain byte-for-byte unchanged for these entries; only their glyph references
changed.

## Generated outputs

The repository generators were run for Classic and Pop, including the Pop glyph
measurement step required for new glyphs. Derived SVG, PNG, banner, appfilter,
document preview, and Pop resources were regenerated by tooling.
