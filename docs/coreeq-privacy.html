Core EQ — Privacy Policy

Core EQ has no account, no analytics, no advertising and no crash reporting of its own. Your measurements are analysed on your TV. This page is the complete account of what leaves your devices, when, and where it goes, including the one part that is Google's rather than Core EQ's: the phone's QR scanner.

Applies to: Core EQ, package tv.corebuilds.eq (GitHub / Downloader release), on the TV and on an Android phone used as its companion, and the test package tv.corebuilds.eq.debug, which behaves the same except that it has no update check.

Effective: 13 November 2026.

There is no account, and no profile of you

Core EQ has no sign-in and no user identifier. It does not read your advertising ID, contacts, location or files. The TV and phone talk to each other only on your local network, and Core EQ's own code contacts only GitHub, and only for updates.

Google's ML Kit documentation says the barcode-scanning libraries send Google device information (manufacturer, model, OS version), app information (package name and version), installation identifiers "not intended to uniquely identify a user or physical device", performance metrics and API configuration, "used for diagnostics and usage analytics", over HTTPS. It does not say the image or the code's content is sent. Core EQ does not turn on the scanner's optional auto-zoom, which collects more. Google (see ML Kit's Android data disclosure)

Nothing else is sent. The Diagnostics summary on Capability and the Support screen's codes are shown on screen and leave the TV only if you press Copy or scan the code yourself. Core EQ sends neither anywhere.

What Core EQ reads on your devices

  • The microphone, only during a measurement you start: on the TV through the remote's microphone, on the phone through its own. The recording is analysed in memory and is not saved on either device. Core EQ never listens in the background.
  • Which audio output is in use, as Android reports it, so each output gets its own correction.
  • Which apps are playing, only if you allow it: through an optional ADB-granted dumpsys read on the TV, or optional Notification access, which checks only whether a notification belongs to a media session and never reads its title or text.

What Core EQ keeps

  • On the TV: your profiles (the measured response curve, the correction, and measurement details such as the microphone and recording device, and which Core EQ builds made and last saved them), your listening settings, and the paired phone's name and pairing token. Android backup can include profiles and settings; the pairing files are excluded from it.
  • On the phone: the paired TV's address and a token, encrypted with a key in Android's Keystore.
  • Exports: a profile file in Downloads/CoreEQ, written only when you press Export.
  • Updates: a downloaded APK, in the app's cache.

Permissions, and why each exists

  • Record audio: for the measurement sweep you start.
  • Modify audio settings: to apply the correction.
  • Dump (optional, granted only over ADB, and refused by many TVs): to identify which apps are playing.
  • Modify system settings (optional, asked only when you switch Stereo speakers on): to set and restore the TV's Surround sound mode.
  • Foreground service and media-playback foreground service: to keep correction running while you watch.
  • Run at startup: to restore correction after the TV restarts.
  • Display over other apps (optional): for the card that says which profile is applied.
  • Post notifications: for the status notification.
  • Internet and network state: for the update check, the update download and the phone link.
  • Local network access: for the phone link, on Android versions that require it.
  • Install unknown apps: to install an update you chose.
  • Write external storage: declared only for Android 9 and older, which Core EQ does not run on; exports use Android's Downloads store instead.

The phone does not need the camera permission: Google's scanner uses the camera itself.

Children

Core EQ is a sound-correction tool. It has no social features, no user content, no chat and no advertising, and it collects no personal information from anyone, including children.

Your control

  • Switch Check for updates on open off on Capability.
  • Type the TV's address and code on the phone instead of scanning.
  • Unpair this phone on the TV revokes a phone; Forget TV on this phone removes the phone's saved token.
  • Clearing Core EQ's data on either device removes everything it keeps there. Core Builds holds nothing about you off your devices, so there is nothing to request, correct or export.
