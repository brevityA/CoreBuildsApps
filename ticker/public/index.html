The three channel apps already publish the slate. Core Line is the reader — a crawl that says Team vs Team · ESPN, TSN4, SN 3.

Setup

Settings

Your RSS feeds

Paste any RSS, Atom, or JSON listing. Channel-list apps, sports blogs, or a homemade XML file all work. Core Line never plays video — it only reads names and channels.

On your phone, same Wi-Fi as this TV. Scan or open the address. Type the code. Do not type the RSS URL on the Stick.

    Scoreboards

    Checked leagues are fetched from public scoreboards and shown as their own tabs. Unchecked leagues are hidden but stay available to re-enable.

    Ticker & display

    Draws the crawl on top of every app, edge to edge. Android TV doesn’t allow overlays, so this is phone/tablet only. Stop it from the notification or untick this box.

    Open games in other apps

    Assign an installed app to each league. Pressing ▶ Watch on a game (or the W key) opens that app so you can watch; “Web browser” opens the game page on ESPN instead.

    Updates

    Core Line updates come from the GitHub release feed. On a TV, download the new APK and the system installer takes over — your settings are kept.

    Help & about

    D-pad: move · OK: select · Air mouse: point & click · S: settings · T: ticker · R: refresh · W: watch · F: fullscreen. This is a TV guide, not a player.

    Core Line reads public scoreboards (ESPN, NHL, MLB) and your own RSS/JSON feeds. It never plays video — the Watch feature hands a game off to the app you choose.
