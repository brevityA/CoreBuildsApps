Three research-backed UX directions

These examples apply Android TV’s current guidance: start with an actionable focus, use predictable D-pad groups, keep the dynamic preview immersive, place browsing in horizontal shelves, and move secondary actions into a selected detail area instead of repeating buttons inside every card.
